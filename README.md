# Proyecto académico – Estructura de Datos (2º Semestre 2023)

Integrantes: Alonso Maurel, Monserrath Morales, Felipe Núñez

## Descripocion

Gestor de empresa telefónica que permite:

- Agregar clientes
- Asignar planes telefónicos
- Aplicar descuentos y roaming
- Gestionar datos mediante estructuras como `ArrayList`, `HashMap`, entre otros

## Cómo ejecutar

1. Clona el repositorio:
   git clone https://github.com/ZZZZIK/Proyecto-SIA-G21-FAMAX

2. Abre el proyecto en tu editor (Visual Studio Code, IntelliJ IDEA o Eclipse)
   
3. Asegúrate de tener instalado:
  - Java JDK 8 o superior
  - Maven
  - 
4. Ejecuta el proyecto desde el archivo Main.java ubicado en:
src/main/java/com/mycompany/proyectosia/Main.java

5. Interactúa con el programa a través de la consola

## Consideraciones

Este proyecto no tiene interfaz gráfica, todas las operaciones se realizan por consola.
